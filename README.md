# 🐶 Dog Care & Pet Adoption Website

## About the Project
Dog Care & Pet Adoption is a web-based platform designed to provide information about dog breeds, dog care, and pet adoption.

The website allows users to explore different dog breeds, learn about dog care, and submit adoption applications.

## Features
- Home Page with an attractive design
- About DogCare section
- Popular Dog Breeds with search and filter
- Dog Care information
- Dog Adoption application form
- Contact form
- Google Sheets database integration
- Email notifications for form submissions
- Admin Login and Adoption Application Management

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
